# Stratify
Stratify is a digital platform that bridges **entrepreneurs (UMKM)** and **investors** through a user-friendly interface powered by analytics.  
The platform is designed to make **entrepreneurial reports easier to analyze**, enabling investors to gain quick insights through interactive data visualizations and real-time communication.

## Features

- **Entrepreneur & Investor Portal** – Structured interface for managing reports, proposals, and analytics.
- **Real-Time Chat** – Built with **Django asynchronous support (ASGI)** to enable direct communication between entrepreneurs and investors.
- **Data Visualization** – Integration with **Chart.js** for interactive charts (bar, line, pie, etc.) to represent financial performance and business insights.
- **Secure & Scalable** – Powered by Django’s robust backend with authentication, ORM, and built-in security features.
- **Responsive UI** – Built using **HTML, CSS, and JavaScript** for modern, mobile-friendly design.

---

## 🛠️ Tech Stack

- **Backend Framework:** [Django](https://www.djangoproject.com/) (with ASGI for async support)
- **Frontend:** HTML, CSS, JavaScript
- **Data Visualization:** [Chart.js](https://www.chartjs.org/)
- **Database:** PostgreSQL (default) or SQLite (for local development)
- **Real-Time Features:** Django Channels (WebSockets support)
